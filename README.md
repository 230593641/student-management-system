# 学生成绩管理系统（C 语言）

一个用 C 语言实现的控制台学生成绩管理系统，支持学生信息的录入、查询、修改、删除、排序、统计，以及数据持久化保存。适合作为数据结构与 C 语言课程设计的入门完整项目。

## 功能列表

| 功能 | 说明 |
| --- | --- |
| 录入学生信息 | 学号（自动查重）、姓名、C语言成绩、数据结构成绩 |
| 显示所有学生 | 表格形式展示学号、姓名、两科成绩、平均分 |
| 按学号查询 | 精确查询 |
| 按姓名查询 | 支持关键字模糊匹配 |
| 修改学生信息 | 按学号定位后更新姓名与成绩 |
| 删除学生 | 按学号删除，数组前移覆盖 |
| 按平均分排序 | 冒泡排序（数据结构经典算法） |
| 成绩统计 | 各科平均分、最高分、最低分、及格率 |
| 文件保存/加载 | 自动保存到 `students.txt`，启动时自动加载 |

## 技术栈

- 语言：C（C99）
- 编译环境：GCC（MinGW-w64）
- 数据存储：文本文件（`students.txt`，程序同目录）

## 如何运行

需要 GCC 编译器（Windows 推荐安装 MinGW-w64 / WinLibs，或用 VS Code + C/C++ 插件）：

```bash
# 1. 编译
gcc main.c -o student_management.exe

# 2. 运行
./student_management.exe
```

也可以直接用 VS Code 打开本目录，按 `F5` 运行（需安装 C/C++ 扩展与 Code Runner）。

## 设计要点

- **模块化函数**：每个功能独立成函数，主循环只做菜单分发
- **输入校验**：成绩限定 0-100，学号查重，防止脏数据
- **数据持久化**：退出自动保存、启动自动加载，数据不丢失
- **注释规范**：每个函数前有功能说明，方便阅读与答辩
